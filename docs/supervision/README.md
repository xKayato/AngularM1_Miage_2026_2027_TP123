# Dossier de Supervision IA

Ce dossier regroupe la documentation technique préparée pour permettre la supervision externe (par exemple par ChatGPT) de l'avancement et de la qualité du TP.

## Contenu du Dossier

| Fichier | Description |
|---|---|
| [PROJECT_ARCHITECTURE.md](PROJECT_ARCHITECTURE.md) | **Architecture globale du projet** : Vue à 360° du projet (arborescence, rôles des dossiers, flux réseau, modèles, stockage disque vs MongoDB Atlas, règles d'or Angular 22 & Express, contrat d'API complet). |
| [MISSION_1_SPECIFICATION.md](MISSION_1_SPECIFICATION.md) | **Spécification & Proposition Mission 1** : Détail des exigences de la Mission 1 (Auth & Profil), réponses aux questions pédagogiques, proposition d'implémentation par composant/service, et stratégie de tests unitaires. |
| [GPT_SUPERVISOR_PROMPT.md](GPT_SUPERVISOR_PROMPT.md) | **Prompt clé en main pour ChatGPT** : Document condensé et autonome prêt à être copié-collé dans ChatGPT, intégrant tout le contexte pour obtenir sa validation ou ses critiques d'architecture. |
